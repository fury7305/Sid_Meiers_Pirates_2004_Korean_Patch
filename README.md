# 스팀판 시드마이어의 해적!(2004) 한글패치
스팀판 시드마이어의 해적!(2004) 한글패치
현재 버전은 전체 게임 검수를 위한 v0.9 테스트 릴리스입니다.
지원 버전
지원
Sid Meier's Pirates! (2004) — Steam
미지원
GOG — 현재 원본 미확보로 미검증/미지원
주요 한글화 범위
- 메뉴 / 옵션
- UI / HUD
- NPC 대화
- 이벤트 및 컷신 자막
- 도시 / 항구 정보
- Trade Notes
- 선술집 / 총독 / 조선공
- 교역
- 함선 관련 UI
- 해전 및 전리품
- 아이템
- 지도 / 퀘스트
- 튜토리얼
- 도움말
- 시스템 메시지
한국어 표시를 위해 별도의 한글 문자열 처리와 폰트 작업을 적용했습니다.
명조 계열 한글 폰트를 사용하며 대화 및 컷신 자막의 가독성을 개선했습니다.
설치 요구사항
- Windows
- Steam 정품 Sid Meier's Pirates! (2004)
- 64-bit Python 3.11 이상
- 최초 적용 시 약 3GB 이상의 여유 공간 권장
설치
ZIP 파일 전체를 게임 폴더 밖의 별도 폴더에 압축 해제합니다.
이후:
실행.cmd
를 실행합니다.
패처가 Steam 설치 위치를 자동으로 검색하고 지원되는 정품 원본인지 검사한 후 한글패치를 적용합니다.
자동 검색에 실패하는 경우 게임 설치 폴더를 직접 지정할 수 있습니다.
주의
Steam 원본 전체 게임 파일은 패치에 포함되어 있지 않습니다.
변조된 원본이나 다른 MOD가 적용된 상태에서는 패치 적용이 거부되거나 정상적인 작동을 보장할 수 없습니다.
현재 GOG판은 지원하지 않습니다.
화면 모드
안정적인 UI 조작을 위해 전체화면 플레이를 권장합니다.
원작의 창모드를 Windows 최대화 기능으로 확대할 경우 마우스 클릭 좌표가 UI와 어긋날 수 있습니다.
v0.9 테스트 안내
현재 버전은 최종 v1.0이 아닙니다.
주요 게임 기능과 한국어 출력을 검증했지만 전체 게임의 모든 이벤트와 엔딩까지의 장시간 플레이 검수는 계속 진행 중입니다.
문제가 발견되면 Issues에 다음 정보를 남겨주세요.
- 발생 위치/상황
- 스크린샷
- 재현 방법
- 번역 문제라면 현재 표시되는 문장
- 프리징/크래시라면 발생 직전 행동
알려진 검수 대상
- 후반부 이벤트
- 엔딩까지 장시간 플레이
- 잔존 영어 문자열
- 번역 문맥 및 자연스러움
- 특수 상황의 줄바꿈/레이아웃
- 프리징 및 진행 불가 여부
배포 정책
본 패치는 원본 게임 전체 또는 원본 실행 파일을 배포하기 위한 것이 아닙니다.
정품 게임 사용자를 대상으로 한 패치 데이터 및 적용 도구만 제공합니다.
