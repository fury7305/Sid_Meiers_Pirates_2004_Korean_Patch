# Sid Meier's Pirates! (2004) Korean Patch

**시드 마이어의 해적! (2004) 한국어 패치**

**Version 0.9 — Public Test**

Sid Meier's Pirates! (2004)의 Steam판을 위한 비공식 한국어 패치 프로젝트입니다.

게임 내 메뉴, 인터페이스, 대화, 컷신 자막, 도시 정보, 교역, 해전, 도움말 등 주요 텍스트를 한국어로 번역했습니다.

한글 출력에 필요한 명조 계열 폰트와 문자열 처리 기능을 포함합니다.

## 다운로드

GitHub 저장소의 **Releases**에서 최신 한글패치를 다운로드할 수 있습니다.

파일명:

`Sid_Meiers_Pirates_2004_Korean_Patch_v0.9.zip`

## 설치 요구사항

- Windows
- Steam 정품 Sid Meier's Pirates! (2004)
- 64-bit Python 3.11 이상
- 약 3GB 이상의 여유 저장 공간
- 최초 런타임 준비를 위한 인터넷 연결

## 설치 방법

1. Steam에서 원본 게임을 설치합니다.
2. Releases에서 한글패치 ZIP 파일을 다운로드합니다.
3. ZIP 파일을 게임 설치 폴더 밖에 압축 해제합니다.
4. `실행.cmd`를 실행합니다.
5. 패처가 Steam 설치 경로를 자동 탐색합니다.
6. 원본 파일의 무결성을 검사합니다.
7. 별도 게임 복사본에 한글패치를 적용합니다.
8. 안내에 따라 한국어판을 실행합니다.

설치 경로 자동 탐색에 실패하면 게임 설치 폴더를 직접 지정할 수 있습니다.

### 포함된 실행 도구

| 파일 | 기능 |
|---|---|
| 실행.cmd | 한글패치 적용 및 실행 |
| 적용.cmd | 패치 적용 |
| 검사.cmd | 패키지 및 원본 검사 |
| 복구.cmd | 비정상 종료 후 임시 자산 복구 |

## 주의사항

**Steam판 전용입니다.**

GOG판 및 다른 배포판은 현재 지원하지 않습니다.

지원하지 않는 원본 버전이나 변조된 게임 파일에는 강제로 패치를 적용하지 마세요.

원본 게임 설치본과 기존 세이브는 직접 변경하지 않는 방식으로 구성되어 있습니다.

한글패치판은 안정적인 UI 조작을 위해 전체화면 사용을 권장합니다.

게임 종료 시에는 게임 메뉴를 통해 정상 종료해 주세요.

## v0.9 테스트 상태

현재 v0.9는 전체 게임 검수를 위한 공개 테스트 버전입니다.

주요 한국어 출력과 패치 적용 기능은 검증했지만, 다음 항목은 추가 검수가 필요합니다.

- 장시간 플레이
- 후반부 이벤트
- 엔딩 정상 진행
- 영어 잔존 여부
- 번역 표현 및 문맥
- 일부 특수 상황의 자막/레이아웃
- 프리징 및 진행 불가 여부

전체 게임의 완전한 무오류 동작이나 100% 번역 품질을 아직 보장하지 않습니다.

## 배포 및 저작권

본 프로젝트는 비공식 팬 한국어 패치입니다.

원본 게임의 저작권은 해당 권리자에게 있습니다.

패치에는 원본 게임 전체, 원본 실행 파일 및 원본 세이브 파일을 포함하지 않습니다.

본 프로젝트는 Firaxis Games, 2K Games 및 Take-Two Interactive의 공식 지원을 받지 않습니다.
